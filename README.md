# FINGENIX - Premium Software Company Portfolio

Building Tomorrow's Digital Experience.

## Overview
FINGENIX is a modern software company that builds premium Android applications, websites, UI/UX designs, AI-powered solutions, Firebase-based systems, APIs, and custom digital products.

## Technologies Used
- HTML5 (Semantic)
- CSS3 (Custom Variables, Flexbox, Grid)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter & Outfit)
- FontAwesome Icons

## Features
- **Premium Design**: Modern, minimal, and luxury aesthetic.
- **Glassmorphism**: Elegant transparent card designs.
- **Responsive**: Fully optimized for Desktop, Tablet, and Mobile.
- **Animations**: Smooth scroll reveal, floating shapes, and animated counters.
- **SEO Optimized**: Meta tags, robots.txt, and sitemap included.

## Project Structure
- `index.html`: Main structure.
- `style.css`: Premium styling.
- `script.js`: Interactive logic.
- `assets/`: Images, icons, and logos.
